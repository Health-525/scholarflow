桌面端、Web、移动端 一致体验

桌面端是主力形态，Web / PWA 随时可用，Android 实验性支持让你随时随地查看课表和笔记。

桌面端 · 完整能力

Electron 加持下的原生体验：系统级安全存储、后台自动刷新、活动窗口统计、自动更新。网页版做不到的事，这里都能做。

Web / PWA · 随时可用

无需安装，打开浏览器就能用。支持 PWA 安装，离线也能查课表、写笔记、看成绩。

Android · 萌系小咪

Capacitor 构建的 Android 应用，专属小咪皮肤，课表、作业、笔记随身查看。

隐私优先

你的数据，
只属于你

ScholarFlow 不是爬虫，也不经营你的数据。它用你自己的学号密码通过学校官方 API 登录，只获取你自己的数据。账号密码 AES-256-GCM 加密存储，学习数据默认落在本地 SQLite。

AES-256-GCM 加密凭证，scrypt 派生密钥
本地 SQLite（WAL 模式），断网可用
零追踪、零广告、零数据采集
代码完全开源，可自行审查每一行
安全架构概览
✓ contextIsolation + nodeIntegration 严格隔离
✓ 内部 API 带 token 校验
✓ safeStorage 记住密码
✓ 图书馆证书显式边界控制
